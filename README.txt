DODGE THE BLOCKS — REAL BIOME AUDIO EDITION

How to run:
1. Extract the entire ZIP to a folder.
2. Keep index.html and the sounds folder together.
3. Open index.html in a modern browser. Start the game to enable audio.

Important:
- Do not move index.html away from the sounds folder; the game loads the recordings using relative paths.
- Real recorded ambience loops for the selected biome. The existing game music and gameplay sound effects remain separate.
- The original audio files are included in sounds/ so you can swap or rename recordings if desired.
